# 推前检查点留下的痕迹

`tools/pre_push_check.sh` 每次运行都会在这里追加一行：它读了哪个 run、那个 run 是什么状态、
放行还是拦下。

**为什么要有这张表**：纪律写着"CI 红着不推 main，实在要推就在提交信息里写明为什么安全"，
但**写在纪律里的规则不算证据** —— 只有能被别人翻出来的东西才算。这张表就是那个能翻出来的东西：
**表里缺哪一次推送，哪一次就是没走检查点的**（2026-10-25 夜那六次就是缺在这儿的，见
`docs/POSTMORTEM.md` 第七轮）。

两件事要知道：

- **这一行随下一个提交进仓库** —— 脚本在推送**之前**运行，那时提交已经写好了，所以那一行只能
  跟着下一次提交走 ✔；
- **它记录的是脚本的判定，不是承诺** —— 那一行说"绿，放行"，意思是那一刻 CI 是绿的 ✔。
